# 聊天加号与智能体项目访问

2026-09-24，v0.1 测试版。

成员点击聊天栏「＋ → 上传附件」，可上传图片、文档或其他文件，单个不超过 256 MiB。上传原件备份至当前项目；成功后自动作为本次请求的附件线索。菜单关闭不卸载上传控制器，进度、错误与恢复操作保留在输入框内。上传未完成时禁止发送，避免任务错过附件。

按最新要求，去掉「选择项目文件」、资料侧栏勾选和文件页「在聊天中引用」。资料侧栏与项目文件页用于浏览、预览和下载；成员只描述任务，服务器智能体自主使用 project_list、project_read、project_attach 查找当前项目、读取资料和返回原件。附件线索不是权限白名单，空线索也可读取当前项目。读取、检索与附件返回权限未扩大到其他项目、其他成员私聊或主机其他目录。删除和修改原资料继续沿用现有审核。
