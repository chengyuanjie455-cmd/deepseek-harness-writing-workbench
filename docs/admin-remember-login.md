# 主机超级管理员记住账号和密码

2026-09-24 用户明确授权增加此功能，仅当前Mac主机管理应用启用。

登录页勾选“记住账号和密码”，首次手动登录成功且服务器返回超级管理员身份后保存。下次打开显示已保存账号，密码框提示“已记住密码，点击登录即可”。仍需主动点击登录，不自动登录；解密后的密码只在桌面主进程送往经核验的本机后台，不返回网页渲染进程。

- 采用当前Electron safeStorage与macOS钥匙串保护加密密钥。应用私有目录只保存0600加密记录，记录包含用户名、密码及服务器身份/地址。Keychain不可用时不退化明文保存。会话Cookie与CSRF仍仅保存在内存。
- 仅已核验的主机应用、当前同一serverId、同一127.0.0.1端口可使用；服务身份或地址变化时不回放密码，不跟随重定向。普通成员、网页和旧成员客户端没有此项权限。
- 退出登录保留记住选项。登录页取消勾选或点击“清除已记住的账号密码”删除保存记录。账号密码失效或原超管被降为成员时，停止使用并清除旧记录；临时断网不自动重试登录，不删除原记录。
- 保存必须由成功登录触发。手动输入失败不覆盖保存记录；使用保存凭据收到401则清除。仅加密保存失败时仍允许本次登录成功，并显示未保存提示。手动输入登录始终可用。
- 系统钥匙串如要求解锁，由机主本人完成；应用没有收集或代填macOS系统密码的功能。

验收：加密/作用域/降权/失效/并发/损坏记录单元测试，加实际Mac包保存→关闭→重开→点击登录，清除和不勾选，以及普通成员网页回归。此功能不改变现有项目、聊天、8位成员账号、后台进程或视频一次创建门禁。

密码记录不能打入安装包、项目资料、Git、普通交付或交接文档。升级保持原bundle身份、应用路径及用户配置目录；旧应用只作回退证据。
