- 主机继续使用现有 Mac 管理桌面端启动／停止后台、配置项目和账号、管理 API 与模板、审核与监控；关闭窗口不停止后台。服务器身份、账号、个人聊天、项目历史、队列和单次创建记录保持原样。
- 成员在同一可互通局域网打开主机控制台显示的统一局域网名称和端口，以账号密码登录；Mac 和 Windows 均使用浏览器，无需安装成员桌面程序或团队证书。成员个人聊天独立，读取同一已发布项目。

- `npm start` 默认启动主机控制台；`node package.cjs` 默认 host，显式 member 构建停止并提示使用网页。旧成员源码和历史测试包暂存为历史，不作为当前分发入口，不声称协议层禁止旧客户端。
