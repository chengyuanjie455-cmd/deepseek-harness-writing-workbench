# 本机候选：Claudian 式工作台侧栏

用户确认在工作台内做完整侧栏。参考对象是本机 Obsidian 插件 `realclaudian` 2.3.20，读取了 manifest、打包脚本和样式；没有修改该插件、导入其运行时或复制其样式包。

## 工作台布局

原有三栏保留。左侧仍是项目分类与集数，新增的侧栏项目选择整合了原来的项目空间、账号菜单和项目切换入口；中间仍是剧本、分镜、资产、视频和剪辑。右侧统一为原生智能体面板，只有一行会话标题和工具：新建聊天、原生历史、会话操作、原生功能与设置。移除了重复的顶部工作台条和独立会话下拉框。

历史直接渲染原生 `sidebar.workspaces`，复用项目、成员和会话树及原生的搜索、重命名、归档等操作。没有再维护一份会话列表或另建会话数据库。管理员的成员聊天仍沿原有后台鉴权和项目入口打开。

插件、自动化等全局功能直接使用原生注册的 `main` 条目，在右栏内显示；文件和终端使用原生 `rightbar`。返回聊天时沿用原来的消息与输入组件。功能面板打开期间聊天子树保留挂载，既有运行和输入状态不会因为面板切换而被重建。项目文件继续在中栏打开。

设置保留原生 SettingsRoot、所有设置分区、提交动作、键盘和模态焦点管理，仅把原生设置 Portal 的目标改为右栏的挂载点。没有重写模型、插件或团队设置表单，也没有删减设置。侧栏宽度支持鼠标拖动、键盘左右调整、Home/End 和双击复位；窄屏继续沿用项目内容与智能体面板切换。

## 功能边界

会话、日志、上下文、工具、附件、权限、图片/视频与 LLM 型号、Queue / Steer 均沿用原生实现。侧栏 UI 不改变既有并发、换型、重提、文件权限和 Skill 保密规则。Claudian 的供应商切换限制没有引入。默认服务未启用此候选布局，安装应用、远端主机和手机端未同步。

独立桌面候选的主机配置可显式设置 `nativeProjectSurface: true`。桌面控制器只在该字段严格为布尔真时，向所启动的后台传入 `PLATFORM_NATIVE_PROJECT_SURFACE=1`；`server/main.ts` 将它交给既有 `Platform` 选项。未配置和布尔假保持原入口，不继承桌面进程偶然带入的该环境变量。候选使用单独的源目录、数据目录、端口和已有验收应用身份；没有修改正式配置。

## 验证范围

本轮只在后台做构建、原生固定版本适配检查、组件结构/尺寸计算测试和整套回归。设置分区和模态管理仍存在于适配后的固定原生模块。组件测试检查功能区域打开时保留原聊天子树，这不等于实际浏览器切换、焦点或终端操作已验收。

浏览器访问此前被权限拒绝，本轮没有换端口、浏览器或底层接口重试。实际界面、窄屏/主题、设置滚动和焦点、项目/成员历史选择、附件草稿以及原件播放仍需可视复测。记录与源码清单保存在本轮输出目录，不把旧版七轮界面流程当作本版已验收。
