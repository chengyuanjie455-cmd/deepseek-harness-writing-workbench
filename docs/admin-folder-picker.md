# 主机文件夹选择与项目工作区

2026-09-28 更新。

- 原生工作台「添加工作区」直接打开操作系统的文件夹选择窗口，不显示自定义添加弹层。选中目录后使用文件夹名称创建项目；沿用原有预览、目录校验与摘要绑定接口。取消不创建项目。
- 设置中更换主机项目文件夹直接调用系统选择窗口。名称、预览差异、绑定及同步设置仍保留。
- 网页管理员需要选择的是服务器目录，因此使用设置页面内的目录浏览区域；不再使用自定义弹窗，不将成员电脑本地目录误当作主机目录。
- 管理员工作区按「项目文件夹 → 团队成员 → 聊天」展示。成员可折叠，聊天行继续使用原生组件，完整历史与附件读取接口保持不变。已有聊天的停用成员保留历史入口，空的停用测试账号不占用列表。

成员自己的原生聊天逻辑、后台设置、模型范围、权限和生成流程保持原有实现。
