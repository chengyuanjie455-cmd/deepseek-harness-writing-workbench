# 项目空间与三栏工作台

2026-10-20 本机网页实现。依据用户本轮连续要求：登录 → 项目文件夹 → 项目内二级侧栏、内容画廊、智能体；剧本为核心；项目资料统一命名展示；聊天资料范围覆盖当前项目全部内容。

## 信息结构

```text
登录
└─ 项目空间：项目卡片、搜索、新建项目；超管可导入主机文件夹
   └─ 打开一个项目
      ├─ 左侧：本项目的二级侧栏
      │  ├─ 剧本
      │  ├─ 分镜
      │  ├─ 资产图：人物 / 角色、场景、道具
      │  ├─ 视频
      │  └─ 剪辑
      ├─ 中间：按剧本集数筛选的内容、预览与原件下载
      └─ 右侧：原生智能体、当前成员的独立聊天
```

分镜、资产、视频、剪辑均位于项目内部，不是项目空间的一级导航。手机按“项目内容 / 智能体”切换显示，原聊天编辑器持续挂载。网页默认进入本机登录页，登录或退出均不自动跳转远程账号站；账号管理与原后台鉴权保持。

## 剧本关联与统一展示

- 以已发布 `补抽索引.json`、冻结方案中的镜头来源和项目目录为依据，组织 EP 集数与人物、场景、道具资产。一项资产可以关联多集。
- 展示名统一为“集数 / 多集关联 / 公共 · 镜头编号（如有） · 类别 · 原名称”。原路径、镜号、轮次、版本及文件内容保留；没有批量改名或移动业务原件。
- 无可靠集数或角色关联的资料显示“公共 / 未分集”或“待分类”，不编造关联。未提供分集索引的整季总稿仍作为总稿，不假称已完成逐集拆分。
- 视频按返回媒体编号匹配同一方案的镜号、冻结提示词、参考资产、轮次。缺失的旧提示词或资产记录明确标记，不能由另一条镜头补齐。
- 剪辑页只展示项目中已有的分集拼接文件与剪辑工程；本轮未剪接或重新生成业务视频。
- 画廊读取授权接口全部分页，支持集数、资产类型和名称过滤；视频列表不同时加载大量播放器，点击预览时加载唯一播放器。

## 右侧聊天的数据范围

右侧聊天可按任务检索当前项目文件夹的全部**已发布**资料，包含未被手动引用的文件。引用卡只是本次请求的重点；不会自动发送聊天或创建生成任务。成员上传内容沿用原平台备份、发布及权限机制。

原生工具 `team_project_files`：

| 操作 | 行为 |
| --- | --- |
| list | 读取当前项目目录、文件版本与总数；支持名称检索和 offset 分页 |
| read | 分段解析当前版本正文，记录真实读取路径；沿用现有文档解析器 |
| attach | 提供当前项目原件、版本、哈希、预览和下载链接 |

每轮原生模型上下文附加当前项目 ID、名称、最新发布版本和首段目录，目录超出一页时保留分页提示。文件按任务读取；目录可检索不代表已理解每份正文或媒体内容。读取失败时明确登记，不把失败说成“没有文件”。

外部修改仍须检测差异并受控导入；不跳过发布版本直接读取主机原目录。切换项目后重新绑定目录、检索工具及聊天，保留原项目聊天草稿，不携带原项目引用。

## 修正的旧访问入口

旧原生提示词及文件工具曾允许访问主机全部目录，与当前项目范围冲突。现已：

- 将原生主机文件工具限制到该成员在当前项目的 `/workspace` 和其原生上传附件目录；真实路径与符号链接同时核对。
- 对复制目录、打包下载的子路径继续执行范围检查，拒绝越界链接；恢复历史文件时核对原历史对象的路径。
- 将全主机 `/api/host-files` 管理接口限为超级管理员；成员读取项目原件使用项目鉴权接口，不能借旧下载链接访问主机任意路径。
- 项目原件下载使用本项目不可变版本，保留原文件名；工作区大文件仍支持断点续传。

这组修改针对已发现的文件工具入口，不等于对所有原生终端、联网能力和宿主 Codex 完成安全认证。未新增任何跨项目授权，也未改变模型目录、价格或生成重试政策。
