# 多项目、主机目录与全员同步（2026-09-24）

成员与超级管理员均可在“设置 → 工作区 → 新建项目”填写名称，由主机建立独立的空白项目文件夹。成员不能指定服务器路径；已有主机文件夹的导入与绑定仍由超级管理员在工作区中选择、预览和确认。

新项目沿用团队可见规则，其他成员从后台读取项目列表；不自动向成员设备复制整个文件夹。2026-10-09 的成员新建能力只在本机后台启用，暂不进行其他主机或外部平台同步。

每个项目独立保存版本、文件快照、成员聊天、任务、成果、媒体和镜头提交次数。所有成员均可访问全部已创建项目；个人聊天独立保留，超管能查看当前项目全部成员会话，成员只能看本人会话。新加入账号同样获得各项目聊天。成员各自切换项目，不影响别人选中的项目或已提交的后台任务。旧项目和旧聊天不重命名、不迁移、不清空。

成员创建接口为 `POST /api/projects`，只接受 `name` 与 `requestId`；请求编号按账号绑定。重复点击或回执丢失后重用原编号，返回原项目；修改同一请求的名称会被拒绝。重复名称、非法编号、目录链接和越权路径被阻断。主机文件删减、已有目录导入和模型管理继续要求超级管理员权限。

## 权限与创建

- 成员与超管均可创建平台自动分配目录的空白项目；选择、导入或重新绑定已有主机目录只限超管。
- 超管导入已有目录时，先冻结预览（目录、文件哈希、名称、项目ID），确认时重读核对。源文件变化、同名项目、重复/父子重叠目录、符号链接、平台数据目录拒绝导入。导入读取原文件，不改写源目录。重复确认返回原项目。
- 目录支持任意类型原件（256 MiB/文件、8 GiB/项目、10000文件），可编辑小文本合计16 MiB。成员上传自动添加到项目，无需登记；常见文档提供文本提取，暂不支持解析的格式仍保留原件。详见project-attachments.md。
- 外部修改按项目检测差异，超管审核导入后才更新共享版本。审批后的成果写入该项目绑定目录；新建项目不会复用另一项目的文件或分镜索引。
- 模型渠道、API密钥、模型目录和流程模板仍由服务器统一管理。新项目要补抽时，超管需发布这个项目自己的剧本—分镜—资产索引。

## 实现与兼容

单个SQLite写者及身份/鉴权表继续沿用。`Store.scoped(projectId)`约束项目数据的读取和写入，拒绝将其他项目的ID覆盖进来；未标注项目的历史记录只属于旧`shared`项目，不进行破坏性迁移。

每个项目有独立`Projects`、Harness执行上下文及媒体任务处理器，共用服务器文本队列、视频在途上限及渠道额度。客户端每次请求显式携带`?project=<ID>`，后台不保存可被其他成员覆盖的全局“当前项目”。会话、任务、版本、审批、素材、补抽计划同时检查项目范围；媒体原件按固定ID及所有者权限提供，成员的私人媒体不会随切换公开。

- GET `/api/projects`：全部已授权团队项目，不返回主机绝对路径。
- POST `/api/projects`：成员或超管用 `{name,requestId}`创建空白项目；同一账号重复请求返回原项目。
- POST `/api/admin/projects/preview`：超管预览 `{name,path}`。
- POST `/api/admin/projects`：用 `{previewId,digest}`确认创建，幂等返回项目。
- 现有文件/会话/任务/审批/补抽/图片接口使用项目查询参数；省略时仍指向原`shared`项目，旧入口与历史ID保持。
- 模型、渠道、账户、全局审核日志、事件游标属于服务器公共管理范围；每条业务事件带项目标识。项目列表新建事件向团队发布，不包含私人聊天。

前端切换项目会使旧请求响应失效，防止迟到结果覆盖新界面；未发送草稿按项目临时保留。提交回执待核对时阻止切换，先恢复原请求。网页URL保留所选项目，刷新后可恢复。项目ID不是鉴权凭据，仍须账号登录。

## 恢复

保持原项目身份、账号与历史。多项目数据库复制到另一位置后，启动会拒绝继续写回原目录。应停服复制全部数据及各个已绑定目录，核验备份后逐项目执行：

```sh
node --import tsx scripts/rebind-restored-project.ts --data /新数据目录 --project /对应项目副本 --project-id 项目ID
```

旧`shared`项目可省略`--project-id`。所有外部绑定项目都核验后才能启动副本。新目录不能与原目录、其他项目目录或数据目录重叠；文件哈希必须与该项目发布版本一致。恢复工具不会替用户复制文件或覆盖原目录。

## 验收边界

使用合成目录验证超管新建、8账号自动同步与并发提交、两项目相同文件名与镜头ID隔离、跨项目ID拒绝、同成员切换、重启恢复、外部差异受控导入和独立目录恢复。真实部署只验证原项目与账号、界面和读接口，不向实际业务项目添加合成资料，不调用付费图片/视频生成。8个浏览器会话不等同8台物理设备持续验收。
