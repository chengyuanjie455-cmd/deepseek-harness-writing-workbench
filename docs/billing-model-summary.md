# 按模型计费汇总

入口：后台管理 → 计费核对 → 模型账单汇总。仅管理员可查看及保存。

- 文字、视频、图片分别统计；同一渠道、模型、币种和计费方式的调用合并，不再逐条列出任务账单。
- 文字汇总输入、输出、缓存读写 token；视频汇总提交秒数；图片汇总提交张数。尚未返回的用量明确提示。
- 支持北京时间的起止日期、模型类型筛选和模型/渠道搜索。结束日期包含当天；“全部日期”恢复全量汇总。
- 费用估算按执行时保存的价格累加。历史调用不会使用今天新改的价格重新计价；未记录的价格显示待核对，不按免费处理。不同币种分别统计，不自动换算。
- GLM Coding Plan 等套餐用量单列。套餐用量不直接视为按量费用；实际金额由管理员依据账单填写。
- 点击“核对模型总账”，一次填写所选日期范围内该模型的实际账单总额及核对依据。该金额覆盖同一范围的旧逐条核对金额，不叠加计算。不同日期范围的核对记录独立保存，只展示当前范围的核对总额。
- 核对后新增调用、用量补录或金额事实改变时，旧核对记录显示“需重新核对”，不计入当前已核对总额。多人同时核对时拒绝覆盖已变化的版本。
- 单价核对仍在“模型单价”页。视频和图片单价在“模型与媒体”中维护。调用记录及审计仍在后台保留，便于追溯。
- 视频时长及图片张数是提交用量；失败或结果未确认的请求不能仅按任务状态推断退款。最终收费以管理员核对的供应商账单为准。

默认 `GET /api/admin/billing` 返回汇总。维护用途可通过 `details=1` 读取原始明细，仍要求管理员权限。模型整笔核对使用 `POST /api/admin/billing/models/reconcile`，校验汇总指纹、核对版本、金额、币种及依据，并记录审计。
