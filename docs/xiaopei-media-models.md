# 小裴图片与视频模型接入（2026-09-24）

用户本轮确认：成员可使用小裴的全部视频、图片模型；不包含聊天与语音模型。超管仍统一保存 API 密钥、维护渠道及并发。成员不可改端点、凭据和协议。

## 目录与能力

后台“API 渠道 → 同步全部视频和图片模型”仅调用小裴 GET /v1/models。按当前账号实际返回的 ID 与已核对的模型协议建立目录；不能依据 openai-video 标签单独判定图片或视频。下架型号停止新确认，已有任务继续按冻结配置回收。

目录完整性、协议适配、真实出片验收分开记录。允许成员使用 testing + memberAccess 模型；此状态不冒充 published 的真实原片验收。公开文档尚未明确参数或调用方式的订制型号，及当前补抽工作流未接入的视频编辑／超分型号，显示在完整目录中并列出待适配原因。本版不能宣称所有型号均已可调用。

协议依据与 SHA-256 保存在 server/data/xiaopei-contracts.json，来自小裴官方工作台、当前 video-generator.js、图片和统一视频接口说明。同步目录不会下载执行第三方代码，也不会调用生成接口。后续新型号需要补齐协议数据及模拟测试；不自动猜参数、替换模型或扩大原片时长。

## 视频

沿用剧本—分镜—资产匹配、超管模板、确认摘要、逐镜时长及人工采用流程。原生首帧模型按首帧角色发送，所需参考原图不足时阻断；画幅跟随首帧的型号不擅自附加画幅参数。参考图与视频不改原字节。当前补抽输入仍使用图片参考，不宣称已实现参考视频、参考音频及视频编辑工作流。

同项目同来源镜头累计 5 次，跨模型及成员不清零；追加申请与核准见 [视频额度规则](video-quota.md)。既有不明请求先恢复，不自动重新创建。

## 图片

成员无需选择模型，直接在主聊天输入框标注模型名称或别名。出现“图片模型：”时，聊天／补抽模式会自动形成图片方案；模型目录只提供查询说明：

```text
图片描述：完整画面描述，包括需要生成的文字原文。
图片模型：gpt-image-2
模型参数：分辨率：1k，画幅：1:1
```

可上传 PNG/JPEG/WebP 原图（单图 24 MiB），或选择本人上传、项目共享原件。原图 ID 会写入“参考图”字段；生成原件不自动成为后续编辑素材。图片不进入视频的五次镜头额度，每个确认只生成一张，不自动重试。

确认卡绑定模型、渠道配置版本、原始提示词、有效参数和参考原件哈希。GPT 图片用 generations / multipart edits；豆姐与标准香蕉用 generations + 经原字节回读的托管 image URL；稳定 4k 的 URL edits 单独映射。参考图不按供应商插件示例压缩、转码或改图。

图片生成是同步接口，后台持久保存提交意图与原响应后下载原件；成员端每 1.5 秒读取平台状态。提交过程中重启或无回执为 submission_unknown，不重新生成。已取得响应但下载失败时只能恢复下载。原件私有保存，超管可读，本人可查看和下载；本版图片没有自动发布/自动采用，人工确认仍待完成。画面文字、人物及美术审查不由解码通过代替。

## 权限与故障

- 所有有副作用的本地接口使用账号、同源与 CSRF 验证；计划和媒体按所有者隔离，超管可查。
- API 密钥只在主机读取，不发到浏览器、提示词、模型目录或交付包。
- 下载只接受 HTTPS 公网地址，固定已解析地址、不跟随重定向、不向结果主机转发 API 密钥；原图有大小上限和内容检查。
- 文本、视频、图片分别排队；图片最多 2 个执行中，并与视频共用渠道在途上限。
- 图片接口错误不会被当作未扣费证明；成本维持“未核实”。


## 超管增删与版本

后台“媒体生成与补抽管理”分别提供视频和图片模型新增、编辑、停用与删除。可维护展示名称、别名、真实模型 ID、所属渠道、参数和默认值；图片须选择已实现的协议，并登记核对依据。账号目录存在不等于协议适配或真实生成通过。

删除移除活动模型配置，阻止新方案确认及尚未发送的创建；保留历史聊天、确认摘要、冻结配置、调用记录、原片和原图。已发出的任务继续按原配置查询和回收。删除操作留审计与目录排除标记，后续同步不会自动复活。确需重新开放，由超管明确新增；新配置版本使旧未提交方案失效，必须重新确认。

同步目录不覆盖超管手工设置的参数、状态或成员权限。成员只能读取开放型号，通过聊天标注名称，不能添加或删除模型、修改 API 地址或密钥。新增型号只限平台已实现的协议；其他协议仍需开发适配器。

## 验收边界

离线模拟覆盖确认幂等、私聊隔离、原字节、参考图权限、下载恢复、提交不明、重启、参数与模型撤销，真实账号只做目录 GET 和网页/桌面读取。没有为了本轮测试付费生成图片或视频。Windows 真机和 8 设备持续 60 分钟验收仍待完成。
