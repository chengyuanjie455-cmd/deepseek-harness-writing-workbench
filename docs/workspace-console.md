# team-harness-platform工作台

工作台沿用原生聊天、多会话、上下文、插件及 Agent 预设。团队层只补充项目、成员、生成记录、审核和运行管理。

- 项目工具 → 项目文件：以项目为一级目录，选择项目后查看文件与内容。
- 项目工具 → 任务中心：以成员为一级分组，每次人工提交形成一条记录，关联生成结果。管理员可查看团队汇总，成员仅看本人提交；原生会话全文继续保存在本人项目聊天中。本人可回到原聊天。
- 项目工具 → 成果审核：按状态、成员或文件筛选，比较新增、修改、删除内容；批准与退回继续使用原有版本检查。
- 原生侧栏 → 添加工作区：管理员选择主机本地文件夹、预览文件并建立项目。成员切换管理员分配的工作区。
- 设置 → 模型：统一维护聊天接口、视频与图片、成员可选范围；成员查看已开放的模型。
- 设置 → 工作区、成员、计费核对、运行与审计：管理员管理团队。
- 设置 → 插件、Agent 预设：直接使用原生功能。设置 → 提示词：维护视频生成模板，项目指令和技能沿用原生机制。

提交汇总来自已持久化的原生日志，不额外调用模型。继承的分支上下文、模型工具调用和子智能体运行不重复列成成员提交。未恢复的运行状态显示为待恢复，原对话记录不删除。

新增设置接入原生 settings.section 插槽，工作区文件夹选择复用现有目录浏览和项目导入接口。未来扩展插件与提示词时沿用这些入口。
