**已明确的调用规则**

视频采用同一套 `POST /v1/videos`、`GET /v1/videos/{task_id}`、`GET /v1/videos/{task_id}/content`。本项目付费入口保持 `https://api.aicopy.top`；官方工作台也使用 `api.aione.help`，两者应分别记录，不能在提交不明后切换域名重发。Bearer 令牌仅由主机持有。`model` 填当前公开模型名，显示名称/别名由平台解析，不向供应商传简称或内部渠道 ID。

请求的 `model`、`prompt`、`seconds`、可选 `size` 在顶层；画幅、分辨率、素材、音频开关等扩展字段放在 `extra`。参考素材要区分单首帧、首尾帧和普通参考；不能把尾帧当普通参考图。`generate_audio` 不能因为视频有声音就默认发送 true；只在型号明确支持且成员选择时发送。文档没有要求 Wan、Mini、H3 必须使用某种专属提示词语法，专用模板属于我们的编排策略，应避免覆盖用户意见。[协议来源](https://api.aione.help/docs/api/video-plugin-api.md)

图片请求有单独规则：GPT Image 类无参考图使用 generations，有参考图使用 multipart edits；豆姐/香蕉分支先取得素材 URL，再用 generations 的 `image` 字段，单图字符串、多图数组。图片比例为 `16x9` 形式，视频为 `16:9`；multipart 边界由客户端生成。图像 `size` 映射按分支尺寸表，不能把“4k”一律解释为 4096 像素。[图片来源](https://api.aione.help/docs/api/image-plugin-api.md)

素材上传的已验证地址是 `https://api.aione.help/v1/uploads`，multipart 字段按素材种类用 image/video/audio。官方页面说明参考素材最长临时保留 60 分钟，不能将上传地址当永久资产库；应保留本地主文件，并在接近提交时上传、回读核验。结果生成后及时回收原片。[工作台说明](https://api.aione.help/)

**需要保留的差异与未知项**

1. **文生视频的版本差异**：v1 文档列出文生视频；3.3.120 更新说明移除了插件文生视频选项，实际入口把旧模式迁移为多参考。源码中部分旧文生分支仍存在，但并非当前模式入口可达。不能把旧分支或通用文档直接当成每个当前型号的保证。
2. **H3 素材条件不同**：在线工作台接受图或音频；最新版插件 H3 入口先检查至少一张图。完整 API 型号 Schema 未公开这一边界。当前以已验证的“带图”路径为依据，音频独立输入保持未核实。
3. **请求追踪不等于幂等**：`extra.request_id` 只被描述为追踪号，未找到按它去重/查回原任务的承诺。创建 POST 可能已经发出时，仍必须保留提交不明并核对原任务，不能自动重发。轮询/下载重试与付费创建重试分别处理。
4. **前端实现不全适合复制**：在线参考图会先按目标画幅加黑边并压缩到约 1024 像素 JPEG；我们此前传原字节。原图和上传衍生图应分别记哈希，不能悄悄改原图。本轮没有加工图片，也不能声称这一步已证明能解决 Mini 的输出画幅问题。
5. **720p 并无精确像素保证**：所取资料提供尺寸/分辨率参数，但没有明确承诺所有型号输出固定为 1280×720。此前 Mini 为 1254×720，H3 为 1376×768，仍不满足测试指定目标；不能仅凭这一点就断言违反了供应商公开的像素承诺。原输入接近 16:9，不能简单归因于成员上传了竖图，详见 [参考图与输出尺寸证据.json](/path/to/local-user/Documents/Codex/2026-09-25/new-chat/docs/provider-api-evidence/参考图与输出尺寸证据.json)。
6. **没有 500 并发服务承诺**：未找到明确的账号 RPM、同时生成上限、排队 SLA、500 路保证、幂等契约或逐任务账单接口文档。网页“可高并发”只是描述。我们自己的 500 配置及模拟通过，不能替代这些供应商条件。

**轮询和恢复的工程结论**

官方网页创建请求等待最长 900 秒、查询约每 5 秒一次；查询的 404/409/425/429/5xx 会继续等待同一任务。客户端接受较多终态别名，但平台应按已验证响应做显式归一化，未知状态保留原回执，不能猜成功。HTTP 200 也可能包含业务错误；先检查错误，再关联任务。`content` 地址出现不一定表示原片已就绪。[工作台实现](https://api.aione.help/assets/video-generator.js?v=sd-933-special-20260909)

我们的实现应保存：成员与项目、冻结输入摘要、准确模型名、规格、费用预约、提交意图、taskId、原始回执、轮询状态、原片字节和哈希。已知 taskId 只恢复同一任务；确认发送前的暂时失败才可安全重排。成员再次修改应形成明确授权的新轮次，关联旧轮次并重新占用预算。以上是本项目执行策略，不宣称供应商已提供幂等保证。
